# Experimental Framework to Investigate Glioma in Organotypic Human Cortex – QuPath Quantification Pipeline

This repository documents the QuPath analysis steps used as the baseline for the quantification of immunohistochemical SOX2 and NeuN staining in organotypic human cortex slice cultures. The script is not intended to be re-run directly, as it includes a record of the steps taken in which parameters were set manually per image due to heterogeneity in staining results across the dataset.

## Files
`SOX2+NeuN_quantificationpipeline_script.groovy` : annotated script generated from QuPath's command history.

## Software
QuPath version 0.5.1

## Extra notes
- Please note the manual steps within the workflow
- The repository does not include:
    - The classifier files as these contain image-specific parameter values
    - The image dataset
